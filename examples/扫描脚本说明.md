# 编写扫描脚本

在工具里添加应用，选择该应用的日志目录和你信任的本地 Python 或 PowerShell 脚本。每次同步，工具把日志目录的绝对路径作为第一个参数传给脚本。脚本以当前 Windows 用户权限独立运行。Python 脚本支持同目录模块，第三方包需要安装在系统 Python 中；没有系统 Python 时，程序使用随附的基础运行环境。

脚本把每次模型调用输出为一行 UTF-8 JSON，写入标准输出。运行诊断可以写入标准错误；非零退出码会终止本次导入。

```json
{"id":"request-384","timestamp":1794800400,"input":40,"output":20,"cache_read":80,"cache_write":0,"model":"demo"}
```

| 字段 | 含义 |
| --- | --- |
| `id` | 字符串。每次模型调用有独立 ID，同一调用每次扫描返回相同 ID。 |
| `timestamp` | 整数。Unix 时间戳，单位为秒。 |
| `input` | 整数。新增输入 Token，扣除缓存读取和写入。 |
| `output` | 整数。输出 Token，如日志的输出已包含思考 Token，直接使用输出总数。 |
| `cache_read`、`cache_write` | 可选整数。缓存读取和写入 Token，默认均为 0。 |
| `model` | 可选字符串。模型名称，默认 `unknown`。 |

示例 `scan_jsonl.py` 会递归读取所选目录的 `*.jsonl`。文件开头给出了它所接受的日志格式。复制示例后，可以按目标应用实际记录的字段修改解析逻辑。下次同步可以重新输出历史记录，工具按调用 ID 去重。
